# Dunara brand assets (official logo)

Source: owner-provided logo (hexagon + partnership figures + DUNARA wordmark).

## Files

| File | Use |
|------|-----|
| `logo-full.png` | Full lockup (mark + wordmark), master crop |
| `logo-primary.png` | Header/footer horizontal lockup (~48px height) |
| `logo-primary.svg` | Scalable SVG lockup |
| `logo-primary-white.svg` | On dark/green surfaces |
| `logo-mark.png` / `logo-mark.svg` | App icon / favicon base |
| `logo-wordmark.png` | Wordmark only |
| `favicon.ico` | 16/32/48 multi-size |
| `icon-*.png` | 16–512 app icons |
| `og-default.png` | 1200×630 Open Graph share image |

## Colour notes

- Figures / check: deep green ≈ `#2E5C0A` (logo art)
- UI primary (buttons, links): `#167A52` (product token in `src/config/brand.ts`)
- Wordmark / hexagon stroke: near-black `#111111`

## Usage

Always use the `BrandLogo` component — do not embed ad-hoc logo copies in pages.
